LanPort — Handheld / Sub-PC installer
=====================================

Python is NOT required. This install ships LanPort.exe only.

1. Start Menu → LanPort (Handheld), or run run-handheld.bat in the install folder.
2. Browser opens http://127.0.0.1:8787/ (LAN: http://<lan-ip>:8787/).
3. On first launch, pick サブ（ハンディ）.
4. Peers appear automatically, or enter the host LAN IP under Manual connect.

Default args: LanPort.exe --role handheld --name Ally

Allow inbound TCP 8787 and UDP 8788 on the LAN firewall.
Host / main PC: install LanPort-Host-Setup.exe.

Repo / releases: https://github.com/cafmie/LanPort
